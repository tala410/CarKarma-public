Политика конфиденциальности CarKarma

Дата последнего обновления: 7 декабря 2024 г.

Введение

CarKarma ("мы", "наше приложение") уважает вашу конфиденциальность и стремится защитить ваши персональные данные. Эта политика конфиденциальности объясняет, как мы собираем, используем и защищаем вашу информацию.

Какие данные мы собираем

1. Данные аутентификации

  • Email адрес (при входе через Google)
  • Apple ID (при входе через Sign in with Apple)
  • Уникальный идентификатор пользователя (Firebase UID)

2. Данные о расходах

  • Информация об автомобилях (марка, модель, год, пробег)
  • Записи о расходах (дата, сумма, категория, описание)
  • Записи о заправках (объем, стоимость, пробег)
  • Фотографии чеков (опционально)
  • Напоминания о техобслуживании

3. Технические данные

  • Версия приложения
  • Версия операционной системы
  • Модель устройства (для аналитики сбоев)

Как мы используем ваши данные

Основное использование

  • Аутентификация: Для входа в приложение и защиты ваших данных
  • Хранение данных: Все данные о расходах хранятся локально на вашем устройстве
  • Синхронизация: При включении облачной синхронизации данные сохраняются в Firebase (Google Cloud)
  • Уведомления: Для отправки напоминаний о техобслуживании и расходах

Мы НЕ используем ваши данные для

  • Рекламы
  • Продажи третьим лицам
  • Профилирования
  • Маркетинга

Где хранятся ваши данные

Локальное хранение

  • Все данные о расходах хранятся локально на вашем устройстве
  • Используется защищенное хранилище iOS (Keychain для чувствительных данных)

Облачное хранение (опционально)

  • При включении синхронизации данные сохраняются в Firebase Firestore (Google Cloud)
  • Серверы расположены в регионе, выбранном Google
  • Данные передаются по защищенному соединению (HTTPS)

Безопасность данных

Мы применяем следующие меры безопасности:

  • Шифрование: Все данные передаются по HTTPS
  • Аутентификация: Используем Firebase Authentication (Google)
  • Локальное хранение: Данные защищены встроенными механизмами iOS
  • Минимизация данных: Собираем только необходимые данные

Ваши права

Вы имеете право:

  • Доступ: Просматривать все ваши данные в приложении
  • Экспорт: Экспортировать данные в PDF формате
  • Удаление: Удалить все данные через настройки приложения
  • Отказ от синхронизации: Отключить облачную синхронизацию в любое время

Удаление данных

Удаление локальных данных

Настройки → Удалить все данные

Удаление аккаунта

Настройки → Выйти из аккаунта → Удалить аккаунт

При удалении аккаунта:

  • Все данные из Firebase будут удалены
  • Локальные данные останутся на устройстве (можно удалить отдельно)

Сторонние сервисы

Мы используем следующие сторонние сервисы:

Firebase (Google)

  • Назначение: Аутентификация и облачное хранение
  • Политика конфиденциальности: https://firebase.google.com/support/privacy

Sign in with Apple

  • Назначение: Аутентификация
  • Политика конфиденциальности: https://www.apple.com/legal/privacy/

Дети

Наше приложение не предназначено для детей младше 13 лет. Мы сознательно не собираем персональные данные детей.

Изменения в политике

Мы можем обновлять эту политику конфиденциальности. О существенных изменениях мы уведомим вас через приложение или email.
