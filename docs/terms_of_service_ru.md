# Условия использования CarKarma

**Дата последнего обновления:** 7 декабря 2024 г.

## 1. Принятие условий

Используя приложение CarKarma ("Приложение"), вы соглашаетесь с настоящими Условиями использования. Если вы не согласны с этими условиями, пожалуйста, не используйте Приложение.

## 2. Описание сервиса

CarKarma — это мобильное приложение для учета расходов на автомобиль, которое позволяет:
- Отслеживать расходы на обслуживание, топливо и другие категории
- Вести учет пробега
- Получать напоминания о техническом обслуживании
- Экспортировать данные в PDF
- Синхронизировать данные через облако (опционально)

## 3. Лицензия на использование

Мы предоставляем вам ограниченную, неисключительную, непередаваемую лицензию на использование Приложения для личных, некоммерческих целей.

### Вы НЕ можете:
- Копировать, модифицировать или распространять Приложение

- Использовать Приложение для незаконных целей

### Ваши данные
